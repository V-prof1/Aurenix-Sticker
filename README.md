# Aurenix Sticker — Android experimental
Editor V1.4 com biblioteca local. Android 10+.
A interface é carregada de um recurso local HTTPS, sem acesso à rede. Arquivos de áudio e vídeo permanecem no aparelho.
Para testar som: gere o vídeo, salve na galeria (Movies/Aurenix Sticker), abra o criador de figurinhas do WhatsApp Business e selecione o vídeo e o áudio original, se a função estiver liberada na conta. Se a gravação produzir WebM, o aplicativo tenta transcodificar localmente para H.264/AAC. Compartilhar vídeo envia um vídeo, não uma figurinha.
Pacotes comuns: selecione 3 a 30 figurinhas de um mesmo tipo e sem áudio; use Adicionar pacote no WhatsApp. A integração oficial não documenta áudio externo em pacotes.
A compilação de teste usa assinatura debug e GitHub Actions. Baixe o artefato APK, extraia o ZIP e instale. Biblioteca do site e do app são separadas: exporte e restaure o backup.
